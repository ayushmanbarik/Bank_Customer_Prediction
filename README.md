# Bank_Customer_Prediction
Developed a Machine Learning-based prediction system to identify bank customers likely to subscribe to term deposits. Performed EDA, data preprocessing, and model comparison using Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting to improve marketing campaign effectiveness.

This project focuses on predicting whether a customer will subscribe to a term deposit through direct marketing campaigns conducted by a Portuguese banking institution. Machine learning algorithms are used to analyze customer information, previous campaign interactions, and economic indicators to identify potential customers and improve marketing effectiveness.

# Problem Statement
The objective is to:
Perform Exploratory Data Analysis (EDA) on banking marketing data.
Develop machine learning models to predict customer subscription.
Compare multiple models and identify the best-performing model.
Provide data-driven recommendations to improve marketing campaigns.

# Dataset Information
Dataset: Bank Additional Full Dataset
Total Records: 41,188
Total Features: 21 (including target variable)
Domain: Banking and Finance
Target Variable: y
Target Classes: Yes / No


# Machine Learning Algorithms
The following algorithms were implemented and compared:
Logistic Regression
Decision Tree Classifier
Random Forest Classifier
Gradient Boosting Classifier

This project demonstrates how machine learning can be applied in the banking sector to predict customer behavior and improve direct marketing campaigns. By comparing multiple classification algorithms, Logistic Regression achieved the best initial F1-score of 46.15%.The developed prediction system can support marketing teams in identifying potential customers and making more informed, data-driven decisions.
